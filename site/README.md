# Studio runtime source

These files are the curated runtime copy of the approved local Horizon/Manrope studio and eight demonstrations from `prototypes/w1/{studio,shared,*-motion}` on October 16, 2026. The original prototype and evidence folders remain in the owner's existing checkout. Only HTML, runtime modules, styles, fixtures, fonts/licenses and used assets were copied; no design reports, prospect records or credentials were copied. This copy is the source for the production path in [the launch decision](../docs/studio-launch.md).

The studio uses EVZ as the visual mark and EVZ Digital as the working public name. The studio inquiry now posts to Netlify Forms; the eight sample journeys continue to simulate booking, purchases, records and automation. The current build and `netlify.toml` deliberately prevent indexing while account delivery, claims and publication checks are open.

Run `node scripts/build-site.mjs` from the repository root to generate `dist/`. The build produces five studio entry pages with HTML content, direct links and distinct page metadata; `site/studio/views.mjs` supplies the same page content to the browser. Run `node scripts/verify-site.mjs` for built route and asset checks. Review and send steps of the inquiry are client-side states on the inquiry page. Public canonical URLs, sitemap and indexing policy wait for verified domain ownership and host setup.
