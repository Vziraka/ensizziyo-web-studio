# Studio runtime source

These files are the curated runtime copy of the approved local Horizon/Manrope studio and eight demonstrations from `prototypes/w1/{studio,shared,*-motion}` on October 16, 2026. The original prototype and evidence folders remain in the owner's existing checkout. Only HTML, runtime modules, styles, fixtures, fonts/licenses and used assets were copied; no design reports, prospect records or credentials were copied. This copy is the source for the production path in [the launch decision](../docs/studio-launch.md).

The studio inquiry now posts to Netlify Forms; the eight sample journeys continue to simulate booking, purchases, records and automation. The current build and `netlify.toml` deliberately prevent indexing while account delivery, claims and publication checks are open.
