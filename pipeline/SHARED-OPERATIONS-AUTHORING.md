Handoff changes eligible work assignment but never changes the preparing actor of an existing attempt.

Exact command input and actor remain in the tab across lost responses/reload/sign-in changes; retry uses the same request. An operator can retain an unresolved request record in the tab and reload current work, which conveys no publication closure or replay permission. Backend exact review/recovery readback determines whether a retry already committed. Immutable source cannot be overwritten for a correction; retain/reconcile the old attempt and explicitly begin from fresh context.

Recovery binds the exact observed state/job/dependency hash, preparing actor, reason and one captured transaction timestamp. Available bytes become immutable hash-named evidence; absent/corrupt/partial dependencies and later in-flight writes retain their honest dispositions. Closing publication does not assert the renderer stopped, make an incomplete export usable, replay a job or reset an allowance. Human/project edits and incoming/background changes may occur during authoring; stale publication and stale recovery observations must fail rather than overwrite them.
