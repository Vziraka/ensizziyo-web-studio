# Production preparation and local operation

Studio Operations stores working records and owner decisions. SOSA discovers/stages prospects; the subscription controller authors and independently reviews detailed assessments. Apollo holds the owner's call tasks and executes email. Gmail verifies sent threads/replies, Calendar owns bookings, and the scoped Google identity projects status to the tracker.

The deterministic local service calls connected tools directly through the installed Codex 0.148.0 app-server. It starts an ephemeral connection session and no model turn. It reuses the existing ChatGPT sign-in and connected accounts; it does not extract cookies, accept new permissions, answer provider approvals, or use a paid model API. This chat is for setup and decisions, not the dispatch loop. SOSA/Dots is not the database or connector transport.

This follows the inspected installed schema and [official app-server protocol](https://learn.chatgpt.com/docs/app-server). Treat CLI/app updates as deliberate compatibility changes. Requested approval, changed account, missing tool or unknown result holds work. Research workers retain separate restricted environments without these connected tools.
