# Renderer test fonts

These static Manrope regular/bold TrueType faces are the same reviewed faces bundled with the installed EVZ proposal template. They are test resources, not a production brand/resource registry. Original project: [Manrope](https://github.com/googlefonts/manrope). The accompanying `manrope-OFL.txt` retains the SIL Open Font License 1.1 and copyright notice.

Tests use real embedded fonts without depending on a user's installed skill path. Register and verify exact private project/template resources separately for actual authoring. Update these fixtures deliberately with the reviewed template, source/lock fingerprints and PDF tests.
