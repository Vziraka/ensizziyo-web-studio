## Signed caller

Use the existing `connectSharedAuthoring` client under `/desk/api/project-author/`:

1. `begin(companyName, 'website-refinement')` resolves an existing Ready item, verifies originals/assignment/context and claims its existing authoring job. `registerRuntime(jobId, runtime)` uploads canonical trusted resource bytes through the existing immutable transfer. No source JSON is supplied by the operator for generation.
2. `authorizeGeneration({policy_sha256, remaining_credits, observed_at, auto_recharge_disabled:true})` is a separately enabled signed owner action for the exact prepared finite policy. It does not select or change a model or amount. Reauthorization/reset/replacement is rejected.
3. `generate(jobId, revision, policyHash)` checks the current exact revision and source/runtime fingerprints and durably reserves the attempt before requesting background execution. `generationStatus(jobId)` returns exact retained attempt/request/schema/raw response and current authoring state. Both signed operators can inspect.
4. `pauseGeneration(policyHash)` durably blocks further phases/adoption/render/review. In-flight effects may still finish; their returned bytes remain untrusted evidence.
5. `continueGeneratedRender(jobId)` is an explicit deterministic continuation for a complete validated source while its authoring job is still Claimed and exact policy/context remain valid. It never invokes inference. Partial Rendering is inspected/reconciled through the existing caller; this operation cannot rerender it.

The dedicated background wrapper is excluded from the catchall. Its tiny body carries only job/attempt IDs and a separately keyed HMAC capability, bound to exact deployment/manifest/policy and a maximum sixty-second dispatch window. It obtains actor/content from the durable claim and rereads trusted state/binding before effects. Interactive cookies are neither forwarded nor accepted as scheduler credentials. There is no schedule. Platform redelivery and duplicate requests read a prior phase claim/result; they never redispatch claimed or uncertain provider work. A lost initial delivery leaves Reserved for explicit investigation/reconciliation.

## Supported source and protected design

The exact selected version must have a hash-verified declarative `authored.json` and a verified original. Imported-only/missing source and runtime/original integrity failures hold before count. Approved composition and wording stay protected by existing explicit heading/body-font and page-background rules. This source increment is deliberately narrower for unapproved versions too: it preserves selected page composition/wording and resources except those supported preferences.

A saved request must explicitly say `Keep composition and wording; apply the supported background rules.` or the same bounded Keep/Preserve grammar with heading/body/font/typography and `and` combinations. At least one supported active preference must exist; unresolved conflicts, broader or ambiguous feedback hold for an explicit decision. Tentative/stale feedback requires explicit defer/preserve records. A model cannot reopen other properties, settle disputes, introduce claims, choose resource bytes or bypass unanswered questions. The same existing `validateAuthored`, preference checks and Node renderer run before publication. This restriction does not claim general natural-language editing.

Instructions and untrusted JSON occupy separate retained content parts. They are both counted and generated using the same text contents: the pinned Gemini Developer API SDK does not support `systemInstruction` in countTokens. Source/request/schema bytes, exact policy, phase claims/reservations, bounded returned text, returned usage/model/catalog and rejection evidence are stored reconstructably in `ai_attempts` and included in G1 state. Original PDFs and runtime binaries are not sent; only registered IDs, resource hashes/reviewed descriptions and selected declarative source/context are included. Saved material is untrusted data, with no tools, arbitrary code, URL fetches or model-directed resources.

The existing Gateway transport accepts an explicit policy only for this caller while retaining all old defaults and exact POST endpoint restrictions. SDK retries remain one attempt. New HTTP decoding and saved text have separate byte bounds. Oversized text is rejected with a bounded prefix, observed full byte count/hash and explicit truncation marker; it cannot be adopted. A transport too large to decode remains uncertain with its durable phase/reservation, never a fabricated output receipt. Missing/mismatched model/catalog/count/usage or incomplete finish holds, retaining rejected response evidence.

## Publication, review and recovery

Only the exact retained response can become validated source. Canonical input is adopted through existing immutable reserve/chunk/complete, then the real registered Node renderer runs. Context/reply/feedback/assignment/restriction/baseline and exact resources are rechecked before count, generation, adoption, rendering and review. A changed context never publishes stale output. Complete authoring still requires separately retained actual PDF PNGs, exact page/export checks and human requirements/semantic/design review. The resulting asset version is unapproved; its companion attachment is exact and held. Baseline selection is a separate attributable action.

Explicit existing `recovery/reconcile` closes authoring publication and the linked inference attempt together, retains its prior status/phases/reservation/raw evidence, and does not attest that an in-flight process stopped. G1 includes complete state/history and existing originals/source/runtime/output/raster dependencies, or explicit incomplete dependency observations. Missing required published chunks fail closed. The advancing-clock correction uses one captured reconciliation transaction timestamp throughout. Late bytes confer no authority. A fresh attempt needs explicit retained-attempt revision, new exact finite policy authority and remaining limits; this caller never repairs automatically.
